Здесь лежат словари для разных версий сайта. В каждый словарь автоматически подключается отдельный файл-контекст с данными для конкретной секции, на основе которых генерируется разметка. Если словаря еще нет, то он создастся автоматически.
Каждый файл словаря предназначен для конкретного layout'a, который используется для генерации страниц под необходимую версию сайта. 
Словарь подключается в соответствующем для него шаблоне в папке layouts командой include ../dictionaries/dictionary.%language_name.pug
