запустить локально: npm start

modules - атомарные, неделимые и самостоятельные модули, которые могут быть везде, типа кнопок, карточек, каруселей и т.п.

sections - отдельные, независимые друг от друга секции страницы, контент которых связан между собой одной идеей-смыслом.

pages - страницы сайта.

иерархия: pages > sections > modules

т.е. страницы состоят из секций, которые состоят из модулей. Множество модулей может являться подмножеством секций, а подмножество секций может являться подмножеством страниц.
