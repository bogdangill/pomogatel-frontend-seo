modules - атомарные, неделимые и самостоятельные модули, которые могут быть везде, типа заголовков, кнопок, ссылок и т.п.
sections - отдельные, независимые друг от друга секции страницы, контент которых связан между собой одной идеей-смыслом.
pages - страницы сайта.

иерархия: pages > sections > modules
т.е. страницы состоят из секций, которые состоят из модулей. множество модулей может являться подмножеством секций, а подмножество секций могут являться подмножеством страниц.
