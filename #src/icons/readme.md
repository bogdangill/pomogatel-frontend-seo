как вытащить конкретную иконку из спрайта?

каждая иконка в спрайте имеет свой id, по которому ее можно вызвать. sprite maker формирует id исходя из того, где лежит иконка, и ее собственного названия(название файла иконки, без формата). т.е. если путь к иконке будет poly->kinds->nanny.svg, то ее id в спрайте будет poly--kinds--nanny
