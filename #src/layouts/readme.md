Здесь лежат шаблоны(layouts) для генерации страниц с общими для них параметрами(язык, цветовая тема, метатеги и т.д.) для конкретной версии сайта(например: СНГ-версия сайта со стандартной темой и русским языком). В каждый шаблон подключен соответствующий файл словаря для определенной языковой версии. Как подключить словарь см. в папке dictionaries в файле readme.
Также в каждом шаблоне присутствует глобальная переменная country в самом верху файла. С помощью этой переменной можно настраивать логику отображения модулей/секций/страниц под конкретную версию сайта.
