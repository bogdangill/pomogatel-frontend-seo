bem-blocks - самостоятельные и независимые бэм-блоки, которые могут примешиваться и использоваться где угодно и на ком угодно(при необходимости). В структуре проекта это просто css классы, у которых нет единого шаблона разметки в силу многовариантности реализации, т.е. они не могут стать полноценными модулями.

modules - атомарные, неделимые и самостоятельные модули, которые могут быть везде, типа кнопок, карточек, каруселей и т.п.

sections - отдельные, независимые друг от друга секции страницы, контент которых связан между собой одной идеей-смыслом.

pages - страницы сайта.

иерархия: pages > sections > modules

т.е. страницы состоят из секций, которые состоят из модулей. Множество модулей может являться подмножеством секций, а подмножество секций может являться подмножеством страниц. Бэм-блоки находятся вне иерархических рамок и подчиняются стандартной БЭМ-логике.
